# LDI · Let’s Do It

1. Carica i file dello ZIP nella radice di una nuova repository GitHub.
2. In **Settings → Pages**, scegli **Deploy from a branch**, ramo **main**, cartella **/(root)** e salva.
3. Apri il link pubblicato in Safari su iPhone. Dal menu Condividi scegli **Aggiungi alla schermata Home**. Apri LDI dall’icona con una connessione per completare la preparazione offline.
4. Crea i gruppi e inizia a inserire le attività dall’icona Home.

I dati vengono salvati localmente. Da **Con chi? → Backup** puoi esportare un JSON con tutti i gruppi e importarlo per ripristinarli. Conserva il JSON in File e tienilo fuori dalla repository. In caso di cambio di telefono, installa l’app e importa il JSON dall’icona Home.
